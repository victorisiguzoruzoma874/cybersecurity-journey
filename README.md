# ⚔️ My Offensive Security Journey

An aspiring **Penetration Tester / Ethical Hacker**, documenting my hands-on path into offensive security (red team).

This repository is my learning portfolio: writeups of the labs, machines, and assignments I complete as I build toward a career in penetration testing — breaking into systems legally and reporting how to fix them. Each writeup shows what I did, what I found, and what I learned, in my own words.

> ⚠️ **Rule #1: Authorization always comes first.** Everything here is performed only in authorized lab environments (Hack The Box, TryHackMe, VulnHub, my own VMs) or against systems I have explicit written permission to test.
